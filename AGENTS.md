# Agent instructions

Read the repository before you edit. Match existing style, tests, and tooling.

- Prefer small, reviewable commits with conventional subjects.
- Run the fastest project check when behavior changes.
- Do not add secrets or credentials to the tree.
- For UI work, load the `distinctive-design` skill before changing layout or color.
- After large generated edits, use `/deslop` or the deslop skill.
- Delegate review to the `reviewer` agent; pipeline YAML to `pipeline-reviewer`; security passes to `security-check`.

# Grill

Decision: $ARGUMENTS

No decision given? The open choice in the conversation or the branch: a TODO, an unanswered review comment, a spec gap. Say which.

A grill turns "we should think about" into "we decided". It is not a quiz.

- **Read the repo first** and settle every question it can answer. Only judgment calls reach the maintainer.
- **Up to five questions a round,** each with your recommended answer and the reason, so "yes" is a valid reply.
- Ask the question whose answer changes the most first. If an answer makes other questions moot, drop them.
- After each round: what is now decided, what is still open, and what changed your recommendation.
- End with a recommendation or an explicit "defer until X". No implementation in the same breath.
- Stop when the next question wouldn't change the decision. Grilling past that point is just being annoying.

**Done when** the decision is written down with its reason, or deferred with a named trigger.

# Design pass

Subject: $ARGUMENTS

No subject given? The screen the working diff touches; with no diff, the one the maintainer has open or the main entry page. Say which.

Load the `distinctive-design` skill and do what it says. This command exists so you don't invent a second process.

- Pick one direction, write it down, build to it. The skill covers how.
- **Prove it on a real capture,** not in prose. Contrast numbers come from the rendered screen.
- Stay inside the subject. Restyling neighbors because you were in the area is how a design pass becomes a rewrite.
- **Ask** before the build only if the maintainer asked to approve the concept first.

**Done when** the reply has the concept, a real screenshot, the contrast pairs and the access notes.

# Handoff

Notes: $ARGUMENTS

No notes given? Write it from the session: the goal, what changed, and what's left.

The next session starts cold. Write what it would otherwise spend twenty minutes rediscovering, and nothing it can read for itself.

- **Goal** in one line, and what done looks like.
- **What is true now,** each line with the command that shows it. "Tests pass" without the command is a rumor from the past.
- **Decisions made, and why.** The why stops the next session re-litigating them.
- **The next step,** concrete enough to start without thinking. Then open questions, each with who can answer it.
- **Traps:** anything that looked right and wasn't, flaky checks, things not to touch.
- One page. Write `handoff.md` unless the repo has its own place for these. Don't start the next session.

**Done when** someone with only the repo and this page could take the next step.
